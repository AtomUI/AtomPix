# AtomPix 第一阶段 MVP 功能范围

> 文档状态：产品范围讨论基线
>
> 基线时间：2026-06-25
>
> 基线范围：当前文档定义第一阶段 MVP 要做什么、暂缓什么，以及基础验收口径
>
> 变更规则：新增、删除或调整第一阶段功能范围时，应先更新本文档，再进入对应架构或实现调整。

## 1. 产品目标

AtomPix 第一阶段目标是交付一款可实际使用的跨平台桌面图片工具，核心围绕：

- 本地图片浏览与预览。
- 图片格式转换。
- 图片压缩。
- 批量处理。

第一阶段不追求成为完整图片编辑器，也不追求覆盖所有专业图像格式。产品重点是把主流图片的压缩、转换和批量处理做稳定、清晰、易用。

## 2. 第一阶段功能范围

第一阶段 MVP 包含以下能力：

```text
1. 打开图片或文件夹并预览
2. 单张图片压缩
3. 批量图片压缩
4. 单张格式转换
5. 批量格式转换
6. 输出目录和覆盖策略
7. 压缩前后大小统计
8. 基础设置
```

## 3. 图片浏览与预览

第一阶段支持：

- 打开单张图片。
- 打开本地文件夹。
- 展示缩略图列表。
- 上一张 / 下一张切换。
- 显示图片基本信息：格式、尺寸、文件大小、路径。
- 适应窗口显示。
- 原始大小显示。
- 放大和缩小。
- EXIF 方向自动校正。
- 拖拽图片或文件夹进入窗口。
- 最近打开记录。

第一阶段暂缓：

- 完整相册管理。
- 标签、收藏、评分。
- 图片搜索。
- 云端图片浏览。
- 多设备同步。

## 4. 图片格式转换

第一阶段支持输入格式：

```text
JPEG / JPG
PNG
WebP
BMP
GIF
TIFF
```

第一阶段支持输出格式：

```text
JPEG / JPG
PNG
WebP
```

第一阶段支持：

- 单张转换。
- 批量转换。
- 输出目录选择。
- 覆盖策略：跳过、覆盖、自动重命名。
- 转换前后文件大小对比。
- 转换失败原因列表。

第一阶段暂缓：

- PDF / EPS / PS。
- 视频帧提取。
- PSD / AI 等设计源文件格式。
- HEIC / AVIF，后续单独评估。

## 5. 图片压缩

第一阶段支持：

- JPEG 质量压缩。
- WebP 质量压缩。
- PNG 优化或转 WebP。
- 最大宽高限制。
- 按百分比缩放。
- 保留或移除元数据。
- 单张压缩。
- 批量压缩。
- 压缩前后大小对比。
- 节省比例统计。
- 压缩结果列表。

第一阶段压缩模式：

```text
智能压缩
高质量
平衡
极限压缩
自定义
```

这些模式在实现上对应不同的质量、缩放和元数据策略。具体参数后续在实现设计中细化。

## 6. 裁剪与尺寸调整

第一阶段支持基础尺寸调整：

- 指定最大宽高。
- 按百分比缩放。
- 批量统一缩放。
- 导出时应用缩放。

裁剪能力作为增强项处理。若第一阶段时间允许，可以支持：

- 固定比例裁剪：1:1、4:3、16:9。
- 自由比例裁剪。

第一阶段暂缓：

- 画笔。
- 文字标注。
- 水印。
- 滤镜。
- 图层。
- 复杂图片编辑器能力。

## 7. 批量任务

第一阶段支持：

- 批量添加文件。
- 批量添加文件夹。
- 任务队列。
- 任务状态：等待、处理中、成功、失败、取消。
- 总进度。
- 单项进度。
- 失败原因展示。
- 失败重试。
- 取消任务。
- 处理完成后打开输出目录。

第一阶段暂缓：

- 暂停 / 恢复。
- 关机后恢复任务。
- 定时任务。
- 后台服务模式。
- 导出处理报告。

## 8. 基础设置

第一阶段支持：

- 默认输出目录。
- 默认覆盖策略。
- 默认压缩模式。
- 默认输出格式。
- 默认是否移除元数据。
- 主题设置。
- 语言设置预留。

第一阶段暂缓：

- 自动检查更新。
- 账号系统。
- 多设备同步设置。
- 企业策略配置。

## 9. 商业化预留

第一阶段不设计复杂付费模式，只预留简单按月订阅架构。

当前产品策略占位：

```text
Free
ActiveSubscription
Expired
```

架构要求：

- 功能本身不区分免费或收费。
- 功能可用性由统一权益策略控制。
- Workflows 在用户流程入口保留权益检查点。
- Desktop 只负责展示订阅状态、限制原因和升级入口。
- Imaging.Magick 不知道订阅、授权、收费或额度。

第一阶段可以预留的功能标识：

```text
SingleCompress
BatchCompress
SingleConvert
BatchConvert
WebpExport
MetadataControl
ResizeOnExport
AdvancedCompressionProfile
```

具体哪些功能免费、哪些功能订阅可用，不在本文档中最终冻结。后续商业策略调整应优先通过权益策略配置或 Core 策略对象完成，而不是散落修改 UI 和图片处理代码。

## 10. 非目标

第一阶段明确不做：

- 完整图片编辑器。
- 云端压缩服务。
- 图片素材管理系统。
- 在线账号体系。
- 企业授权系统。
- 插件系统。
- PDF / EPS / PS 处理。
- 视频处理。
- 专业设计文件处理。
- HEIC / AVIF，除非后续验证成本可控。

## 11. 基础验收口径

第一阶段功能验收至少覆盖：

- 能打开本地单张图片并显示预览。
- 能打开本地文件夹并浏览图片列表。
- 能对单张 JPEG / PNG / WebP 执行压缩。
- 能对多张图片执行批量压缩。
- 能将主流输入格式转换为 JPEG / PNG / WebP。
- 能显示压缩或转换前后的文件大小。
- 能展示批量任务成功、失败、取消状态。
- 能选择输出目录并应用覆盖策略。
- 能保存并读取基础设置。
- 关键用户流程通过 Workflows 进入，不绕过权益检查点和业务规则。
